# M8 redistribution review — 22 October 2026

The local qualification package is deliberately not a public release. No upload or public distribution is performed by local build scripts. The optional GitHub workflow is explicit, gated and creates a draft for human review.

- **ADM original code:** owner has not yet selected a source/distribution licence. Proposed choice is MIT; accepting that proposal would permit modification and commercial redistribution too. Merely describing ADM as freeware does not resolve that choice. No root LICENSE has been silently imposed.
- **.NET, Microsoft.Extensions, Microsoft.Data.Sqlite:** installed package metadata identifies MIT. Runtime licence and third-party notices are copied into the package. Primary reference: https://github.com/dotnet/runtime/blob/main/LICENSE.TXT ; MIT terms: https://opensource.org/license/mit .
- **SQLitePCLRaw 2.1.13:** Apache-2.0, Copyright 2014–2024 SourceGear, LLC, per installed NuGet metadata. Official Apache licence text is retained. Bundled SQLite is separately covered in upstream package/runtime notices. Exact package versions and supplied notices are recorded with the payload.
- **SimConnect:** development uses the official locally installed MSFS 2024 SDK. The installed SDK EULA restricts redistribution except distributable code, but the installation has no file-specific SimConnect grant that we could verify. The official developer forum still has an unanswered request covering the same native/managed pair: https://devsupport.flightsimulator.com/t/redistribution-permission-for-msfs-2024-simconnect-dlls/18295 . A local runtime-only package is technically tested so pilots do not need the SDK; public shipping of that pair remains gated on an appropriate permission determination. No SDK tools, headers, samples or full SDK installer are included. Do not claim the deployment test establishes redistribution rights.
- **Supplied notification MP3:** retained unchanged, SHA-256 D03BBDF4F72384121A72FAFBEB4C19D84E018DF8528E819F608F88F203AB76D1. Filename suggests an external sound-library asset; the exact source licence/certificate is not provided and was not independently verified. Confirm public app-bundling rights before release; do not relicense it as ADM original code. General library terms do not prove this file's provenance.
- **Supplied project logo:** encoded unchanged into the executable/installer icon at the owner's request. Keep its original artwork provenance with the release assets; no third-party ownership claim is made.
- **MSFS/GSX/Any2GSX:** separately installed products; no product binaries other than the local SimConnect qualification pair are included. No affiliate/endorsement claim.

MIT is a proposal for the owner's decision, not legal advice or a claim that third-party assets fall under it. The Windows/aircraft live matrix and clean-machine installer qualification remain separate release gates.
