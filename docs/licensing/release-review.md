The local qualification package is deliberately not a public release. No upload or public distribution is performed by local build scripts. The optional GitHub workflow is explicit, gated and creates a draft for human review.

- **SimConnect:** on 23 October 2026 the project owner confirmed: “I can confirm that the sim connect files can be distributed with the addon”. ADM records this as owner confirmation covering the matched native SimConnect.dll and managed Microsoft.FlightSimulator.SimConnect.dll client pair bundled with the addon, and closes the project redistribution check on that basis. This record is not an independently obtained Microsoft permission letter or a new licence grant. Microsoft ownership and applicable third-party terms remain unchanged. Only the client runtime pair is packaged; no SDK tools, headers, samples or full SDK installer are included. Pilots do not need the SDK.
- **Notification media:** outgoing Pop by DRAGON-STUDIO (Pixabay 402324) has a verified official asset page and Content License link. The owner confirms the incoming MP3 also came from Pixabay; its exact asset page was not independently retrieved. Hashes, URLs and provenance are recorded in media-provenance.json. Notices are shipped separately from ADM's code licence; these assets are integrated feedback, not standalone sound downloads.
- **Supplied project logo:** encoded unchanged into the executable/installer icon at the owner's request. Keep its original artwork provenance with the release assets; no third-party ownership claim is made.
- **MSFS/GSX/Any2GSX:** separately installed products; no product binaries other than the SimConnect client runtime pair are included. No affiliate/endorsement claim.

The selected ADM freeware licence does not relicense Microsoft files, dependency code or third-party media. The Windows/aircraft live matrix and clean-machine installer qualification remain separate release gates.
